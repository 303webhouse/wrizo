## COMMITTEE PASS — the page's beginnings (SV17)

**The charge:** Nick asked whether a fresh page should offer a kind —
"Blank, Screenplay, Outline, Journal Entry, Mixed Media."

**Experts — the finding, which reframes the question.** Four of the
five proposed kinds are not page kinds at all. *Journal Entry* was
abolished by SV6 — the Journal is a home (an `origin`), not a type; a
picker offering it would resurrect the thing FX14 just buried.
*Outline* is a Board projection — a page cannot be an outline; a board
can. *Mixed Media* is two different capabilities: ink (already built,
a tool) and images (Reference-Seal territory, post-vacation). *Blank*
is not a choice, it is the default state of paper. **What actually
remains is one real axis — structure: Prose or Screenplay** — plus two
things that are doors, not kinds.

**Marketing — the opposition, sustained.** "The app funnels you
straight into your writing" is the product's own sentence. A picker
that stands between the writer and the first word is friction dressed
as helpfulness, and every writing app that ships a new-document
template gallery is selling ceremony. If the page asks a question
before it accepts a word, we have built the blank page's bureaucracy.

**Architects — the resolution.** The row is not a gate. **The page is
already live and typeable the instant it renders; the beginnings row
is furniture beside the cursor, and the writer's first keystroke
dismisses it** — the A19 staged-vanish law, already ratified, applied
verbatim. Four doors, one row, no grid, quiet olive:

- **Screenplay** — flips structure (the existing prose/screenplay
  toggle, surfaced at the moment it is cheapest to choose).
- **Start from a Spark** — draws a line from the deck (deck-drawn,
  never model-drawn), on request only.
- **Plan this first** — opens the page's paired plan board (the PLAN →
  door, offered at birth: this is the Page→Plan pipeline's on-ramp).
- **Bring a Reference** — deferred until the Reference Seal exists;
  the row ships with three.

**Prose needs no door** — it is what the paper already is. And the row
never renders on a page that has words.

## BG1 — the Beginnings (board + page) · **owner: chat 3**

Branch `bg1-beginnings`. **Authority:** SV3 (ratified), Chamber A of
the batch-sitting pass, plus SV17 and the committee pass above.

**S1 — the board's row.** As Chamber A tabled: centered, quiet olive
icon+label doors, no grid, rendered only while the board has zero
boxes, gone the instant it has furniture. Per mode — OPEN: New Card ·
New Page Card (births a linked page) · Load a Deck · Connect a Page.
STORYBOARD: Load a Deck · New Lane · New Card. OUTLINE: New Card ·
Load a Deck. Paired plan boards use OPEN's row. **System boards
(Journal/Shelf/Trash) never render a row** — their empty states stay
declarative lines. Import/Upload doors do NOT ship (Reference Seal
pending).

**S2 — the page's row.** The three doors above, beside the cursor on a
page with zero words; dismissed by the first keystroke (A19), by any
door taken, or by Esc. **It never blocks typing** — the caret is live
under it from the first frame; a harness check must prove a writer can
type immediately without touching the row and that the row is gone
when they do.

**S3 — one grammar.** Board row and page row share one component and
one vanish rule. Nothing counted, no completion state, no "get
started" checklist language. Doors, not tasks.

**DoD:** a fresh board is never a dead end; a fresh page never asks
permission; both rows disappear the moment work exists.

## PB1 — Born on the First Word · **owner: chat 4, after SC2**

Branch `pb1-born-on-first-word`. **Authority:** the export's finding —
~45 empty Untitled pages and duplicate empty boards in Nick's real
corpus; the doors bred them.

**S1 — root-cause first.** Name precisely where a page (and a board)
is persisted on arrival rather than on content. Reproduce: open a New
Page, navigate away without typing, check Places. Do not patch before
the mechanism is named.

**S2 — the rule.** A page is born when it has a word; a board when it
has a box. Before that it is a live, typeable surface with no
persisted row and no Places entry. **Local-first invariants hold
absolutely:** the moment content exists it persists immediately
(offline included) — this ticket may not introduce one keystroke of
loss. If birth-on-content risks any loss window, STOP and report; a
lazy-birth-on-first-change design that persists synchronously is the
only acceptable shape.

**S3 — no sweeper.** Existing empties are not deleted by code; Nick's
wipe already cleared his. Never a background reaper.

**DoD:** the app stops collecting rooms nobody entered.
**Order note:** last in the wave. If any lane runs short of time, PB1
is the one that waits — it touches the most core path.
