## THE ASK

Opening a board from the Plan door arrived on **OUTLINE**. Measure whether the
board's stored view *was* outline (Q6 stickiness working) or whether the default
is wrong — **and report which before anything is called a bug.**

## THE VERDICT: STICKINESS, BY ELIMINATION FROM CODE

| fact | where |
|---|---|
| A board's view is per-board and **client-local** — the `localStorage` map `wrizo-board-mode` | `store/boardMode.ts` |
| **The default is `open`** when nothing is stored (`getBoardMode` falls through to it) | `boardMode.ts:42` |
| The Plan door does `getOrCreatePlanBoard(pageId)` then a plain `navigate('/page/<id>')` — **it passes no mode and writes none** | `PageEditor.tsx:542` |
| `BoardEditor` forces `open` **only** for system boards; otherwise it renders the stored mode | `BoardEditor.tsx:744` |
| **The only code anywhere in the app that writes a board's mode is the writer's own click on the mode tab** | `BoardEditor.tsx:2467` |

**Therefore:** landing on OUTLINE means that board **had `outline` stored for it,
in that browser** — set by a previous click on its own Outline tab. **Q6
stickiness was working, and the default was correct.** Nothing here was a bug.

## WHAT THIS IS NOT

**It is elimination from code, not observation of Nick's board.** His stored value
lives in his browser and cannot be read from here. One line in the devtools
console on that board turns the elimination into an observation:

```js
JSON.parse(localStorage.getItem('wrizo-board-mode'))
```

It should carry `outline` against that board's id.

**One adjacent fact, not a bug but worth knowing:** the view is **not synced**. A
board set to Outline on one device opens on `open` on another, because the map is
client-local by design (zero schema).

## WHY IT DISSOLVES

Item 172 makes **Outline a kind of board** rather than a view of one. Once a
board *is* an Outline board, "which view did it open in" stops being a question
about stored state and becomes a question about what the board *is*. The
verdict above stands as the record of the old model.

**Still open, and Nick's to rule:** whether the Plan door should **override**
stickiness — always opening its own view regardless of what the writer last
chose. That question survives 172 in a changed form and is not answered here.
