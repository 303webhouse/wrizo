## §4 · THE DRIFT CHECK — THE TICKET'S MOST DURABLE ARTIFACT

`apps/desktop/scripts/harness/tutor-mirror.mjs`, **5 checks**. Static and
browserless, the same shape as `hooks-order.mjs`: it costs the suite
milliseconds and no browser.

It extracts the template literal, takes the mirror's body after the `---`, and
asserts they agree — plus a paragraph-count echo, so a reader of a red run can
tell at a glance whether a whole block went missing or one character changed.

**It deliberately has NO opinion on prompt CONTENT** — not on what the Tutor
should say, which paragraphs exist, or where they sit. Byte-agreement is the
only claim the mirror's header makes, and a check that quietly grew opinions
about wording would start failing for reasons nobody signed up for.

**FALSIFIED TWICE, and the first is not hypothetical:**

- **(A) against `origin/main`'s REAL state** — **2/5 failed**, reporting
  `prompt=2422 mirror=1988` and `prompt=5 blocks mirror=4`. **The check's first
  real falsification caught the actual shipped defect, not a synthetic one.**
- **(B) against 113 applied to the prompt with the mirror forgotten** —
  **2/5 failed**. That is precisely the future this check exists to prevent.

## §5 · THE FALSIFICATION CAUGHT A BUG IN THE CHECK ITSELF

Recorded because it nearly shipped, and because it is the reason to falsify
against reality rather than a convenient fixture.

The first draft split the mirror on an LF-only separator. This repo runs
`core.autocrlf=true` with **no `.gitattributes`**, so a checkout writes **CRLF**
— the separator never matched, and **the equality check never ran at all**
(3 checks instead of 5) while the run reported a misleading *"no separator"*
failure.

It went red — but for the wrong reason, **which is its own kind of lying**: a
guard that fails on checkout policy rather than on content would have been
disbelieved and then disabled, and the real divergence would have stayed
invisible behind it.

Line endings are now normalised to LF before anything is compared. That compares
**what git stores** rather than what a given checkout happens to write, so the
check cannot disagree with itself between this desk, another machine, and CI.
