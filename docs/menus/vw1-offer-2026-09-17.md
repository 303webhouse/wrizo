## §5 · COMMIT 3 — THE THIRD FORM, TWO PARKS, CHECK 7 INVERTED

**38 more sites**, found only because the regroup broke them: `ab4`, `cd2`
and `fx9` each carried a local `clickCategory(app, idx)` helper doing
`items[${idx}]`, called with plain integers. The helpers now take a category
and **throw at the site** rather than silently doing nothing when absent or
silently pressing the wrong tab when present.

**Check 7 is inverted, not widened a third time.** A grep that enumerates
spellings sees only the spellings someone imagined, and this file had already
been bitten twice widening it. The rule now: any live `.wz-strip-item`
reference that is not a `[data-category=…]` selector is an offender unless it
is a **named, justified exemption** — population counts, whole-set
collections, the last-asserted-as-last read, uniform style reads, selector
constants, the instrument's own source. The one exemption that cannot be
decided by a line's own spelling — `const items = [...]`, assigned then
possibly indexed later — is resolved by a **dependency check**: lawful only
if nothing ever indexes the variable. Exempting the spelling would have
reopened the exact hole the inversion exists to close.

**Check 7 itself had a runtime crash, found only by extracting its logic and
running it — `node --check` had passed on it three times.**
`` new RegExp(`\b${v}\s*\[`) `` has its escapes eaten by the *template*
before `RegExp` ever sees them: `\b` became a backspace byte, `\s` a literal
`s`, `\[` an unmatched bracket — `SyntaxError: Unterminated character class`
at runtime. Fixed with `String.raw`. **A file that parses is not a file whose
regexes compile**, and a static check of a static checker proves nothing —
only executing it against real input does.

**Two live offenders converted**, both green for the wrong reason:
`item133.mjs` pressed bare `.wz-strip-item` — whichever tab is first — and
passed before and after only because any tab opens the cascade; `item83f.mjs`
selected by label text behind a guard that swallowed a miss.

**Two files parked, four entries.** `b1` and `cd1` each pin the old order
**twice** — once live, once in a gated `pok()` twin — so the parked leg
failed **different checks from the default leg**, inside one turn: the
sharpest evidence this arc has for "both legs always run" as a law rather
than a convenience. Each entry parked verbatim with a named successor
comparing the eight labels as a **set**; order is asserted nowhere but
`vw1.mjs` now.
