# ITEM 207b — S1 BUILT (browserless): the door, the per-device library, the quiet mark (tools lane; branch `item207b-device-fonts`)
### `item207-core.mjs` 68/68 (park count 1, both legs); `item207b.mjs` (rendered) written, syntax-checked, NOT RUN; both S0 probes still owed. Rulings applied: the library is per-device; a missing face shows its fallback and the quiet "Substituted on this device" mark.

## What is built
- **`store/deviceFonts.ts`** — the library (`wrizo-device-fonts`, per-device `localStorage`, `[{ name, generic }]`, cap 200, corrupt value = empty, de-duplicated, refreshing on re-add), `storedFaceForDevice` (`source: 'device'`, no fallback file — the class IS the fallback), `localFontsSupported()`, and `listInstalledFamilies()` — the only call into Local Font Access: unique sorted family NAMES, a face's bytes (`blob`) never touched, and a refusal is a VALUE (`unsupported | denied | failed`), never an exception.
- **`store/fontDetect.ts`** (S0) — `isFontAvailable` and `classifyGeneric` (canvas), asking about ONE name at a time.
- **`TypeControl.tsx`** — the roster is the nine plus every font added on this device (Free Write and the card show the same list). **The door — "Add a font…" — is the roster's last row in the FULL form only, and only where the browser has Local Font Access** (`const canAdd = form === 'full' && localFontsSupported()`): absent, never greyed, in Free Write, on a card, on Firefox and Safari. It **drills in inside the same listbox** (166's R2), lists this device's families each in its own face, and a pick measures the class, adds it to the library and sets it on the page. **Nothing enumerates until that click** (the browser's permission is asked then, never on load). A refusal is one plain sentence in the list; Escape steps back, then closes. **Still exactly three buttons and one input** — the door is a row.
- **The mark:** a `device` face this device lacks sets `data-substituted` on the face button (dimmed italic), with the sentence in its `title` and accessible name. **No toast, no extra element, no caption.** The two named faces (Times New Roman, Arial) never nag — their fallback is metric-compatible.
- **No schema, no server, no font bytes:** a device font renders by name; `pageSettings.face` already syncs whole; the library never leaves the device (asserted).
- CSS: the list scrolls (`max-height: 16rem`); the drill-in rows use `content-visibility:auto` so a device with hundreds of families paints only what is scrolled into view — **an assumption the S0 probe's cost measurement will confirm or refute.**
