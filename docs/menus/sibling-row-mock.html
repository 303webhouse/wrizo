Two lists of boards, and you should never confuse them. On the left, the membership zone exactly as PW2 ruled it — the board’s name, then Pages and Boards, with “linked to this board” living only in the accessible name. Below the board, the sibling row: tabs, labelled by the drawer (Novel) because siblinghood means where this sits. Place, form and word all differ — and the word matters most, because PW2’s ruling removed the one visible phrase that said “membership.” Press a tab and the board changes over (travel, never nest). Add tags from the dashed set: each one narrows (ALL — tags are a sorting mechanism). Active tags sit in the order you added them, each with its own ×, and clear all is a separate act. Add #lore after #stark and the sort empties — and it says so in words, naming the tags, so it reads as a sort and not as breakage. Tagged pages and cards appear in a strip under the tabs (SR-Q1’s lean), never as tabs.
