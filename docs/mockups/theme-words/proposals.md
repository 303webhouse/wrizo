# Theme-words proposals

Source: `docs/vocab/label-census.md` @ `vocab-census` `a788a64`.

Already unique (no candidates; shown with “?” in the mockup): Pages / Docs, Boards / Circuits, Plan / Schematic, Journal / Log, Publish / Uplink, Grafts / LINKS, Rhizome / Glitch.
