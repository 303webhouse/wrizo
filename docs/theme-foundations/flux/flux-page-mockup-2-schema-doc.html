The Flux page as a node in the circuit. The same doc, read as a record: each paragraph is a block with an id and a word count in a schema gutter, and the links this doc has to circuit nodes leave the page as traces to those nodes, waiting out in the room.

  • Electrons where you are, as on the circuit: the traces always move; the block your caret is in fires electrons along its own links, and its node lights up.
  • The rail is the board's command boxes, variant B: each box has a readout line under its name (counts, what is open), a bracket corner when current, the place you are in in orange, and "Last node" always one box away.
  • The sprint readout is a segmented bar (one segment per 15 words) whose letters glitch, then resolve; at the goal it hands off to orange and the letters resolve to CHECKPOINT.
  • The hands and + match the circuit. Writing fades the gutter, the traces' nodes and all chrome; the words stay.
