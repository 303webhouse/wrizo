Mockup B — STRATA

The Flux Circuit as layers of reality in depth. The same board, pulled apart into the strata it is already made of:

  • SUBSTRATE — the ground is a rain of code made of your own words, falling as glyphs. Language as code, literally.
  • SCHEMA — the structure: your groups as lime-bracketed regions, the reading-order spine.
  • NODES — your cards as holographic record panes.
  • BUS — your links rise off the node plane as light beams and cross on a bus layer above it, packets running along them.

Drag the Strata slider (or press F) to flatten everything back onto one plane, top-down: work mode is the familiar board, the spectacle is one gesture away and back.

Infinite zoom, in levels

  • In: zoom past a node (or double-click it) and you enter it. Inside, the card's text is shown as source — line numbers, tokens coloured as identifiers, keywords, operators and constants — beside its schema (id, kind, group, links written as function calls). It is still your text; you can edit it there, with the orange caret.
  • Out: zoom past the circuit and it collapses into a cube in its cartridge, among its sibling circuits; keep going: the cartridge in its rack, the rack in the cache, then unindexed space, without end.

Humanity as a bug

Every few seconds a scan plane sweeps the node layer looking for human artefacts. Each node it crosses flags HUMAN ARTEFACT // UNCORRECTABLE in orange and settles back. The inside view lists the card's "bugs": one, always — you. All of it is theatre: no stored word is ever changed.

Familiar, not lost

  • Nodes keep the card's own x / y and size on their layer: flatten and you are looking at your board.
  • Orange is you: the last node you touched carries the orange bar and an orange beacon that rises through every layer, so it can be seen from any angle. Locate last node flies there.
  • Jack out flattens and redraws the same cards as Arbor cards in place.

The design team (two passes)

Same convening as Mockup A: sci-fi game UI, motion / VFX, data-visualisation, with the house Experts and Architects. This is the spectacle direction. Pass 2's trims that shaped it: the code rain is only the substrate and dims while you work; 3D is never required to work (flatten is always one key); the camera never moves on its own except when you ask (Locate, Flatten); glitch and scan stay under 3 Hz and damp while you drag or type; reduced motion stops the rain, beams and scan.

What this mockup does not decide (would go to Fable)

  • A 3D stage is a new board renderer for Flux only — an architecture pass. Mapping layers to data uses only fields that exist (kind, groupId, links, lit, order).
  • Remembering the camera / strata amount would be a new saved field; here it lives in memory.
  • Editing "source" inside a node writes the card's ordinary text; no new storage.
