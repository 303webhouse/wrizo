Mockup A — SCHEMA, v2

Nick picked Schema. This version takes his ten notes of Oct 27:

  • Electrons only where you are looking. At rest a link is a moving dashed trace with no electrons. Select a node and its links fire electric-blue electrons. Dragging a new link fires nothing; the moment it connects, the trace lights up (the connection is established), then settles.
  • Slower. Link electrons run slower; the ground's current runs at the same speed on fewer traces.
  • No token count. The footer now says how many links a node has — the number of things it is connected to.
  • Kinds, labelled. PRESET (a card dealt from a preset, with its preset's name) in lime; DOC (a page) in orange; and for imported files their own type — PDF, JPG — next to TEXT and INK.
  • The two hands, redrawn. TOOLS (left) and OPERATOR (right, the Tutor) are circuit-drawn hands; each opens a holographic panel over the surface (never pushing it), its contents follow what you are looking at.
  • The + square, right of the surface: a new connected circuit, open an existing circuit, connect a new or existing doc, disconnect this circuit.
  • Split screen. Whatever + opens comes up beside it — up to four panes (three splits). One ground runs behind every pane; each pane keeps its own links. Connected panes are joined by a trace across the ground.
  • An opened node is a hologram. Double-click a node (or the centre of the stack): it becomes the surface, projected over an emitter. Swipe, drag, wheel or arrow keys flip through the others like holograms. The hands and a + (new node, link an existing node, unlink) come with it.
  • Stack view: every node, doc and file flies out of its place on the circuit into one stack you can swipe through; leaving Stack flies them home. The circuit stays faintly behind, so you see where each one came from.

What would be new data (would go to Fable)

  • PDF and JPG nodes: the board stores text, ink and page pins today. Imported files would be a new card kind.
  • Orange for docs: the Flux canon keeps orange for the writer's own acts. Nick asked for docs in orange; Fable should rule how that sits with the orange "last node" bar.
  • Split screen and the 3D stack / hologram are new stage machinery, an architecture pass. Opening two surfaces at once must keep page primacy: no pane may move or resize another while you write.
  • Board-to-board and board-to-page connections already exist (PW1). Remembering panes, camera and stack position would be new saved fields.

Unchanged from v1

Infinite zoom (node → circuit → cartridge → rack → cache → unindexed, and in to code points), the Signal-Loss glitch on the ground only, damped while you drag or type, humanity as a bug (the autocorrect that is always rejected; no stored word ever changes), Locate last node, Jack out to Arbor.
